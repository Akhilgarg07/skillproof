answer
In semantic versioning (MAJOR.MINOR.PATCH), a MAJOR bump means the release has breaking changes to the public API, so code that worked with the old version may stop working. When MAJOR goes up, MINOR and PATCH reset to 0, for example 2.4.1 → 3.0.0.
