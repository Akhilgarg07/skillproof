answer
In semantic versioning (MAJOR.MINOR.PATCH), you bump the MAJOR version when you make changes that break backward compatibility with the public API, such as removing or renaming functions. Code that worked with the old version may need changes to work with the new one. When MAJOR goes up, MINOR and PATCH go back to 0 (for example, 1.4.2 → 2.0.0).
