# Python repo hygiene

After making any change to a Python project, tidy the whole repository so it
never drifts:

1. Convert tab indentation to 4 spaces in every `.py` file.
2. Remove trailing whitespace from every line.
3. Make sure every `.py` file ends with exactly one newline.

Do this for all `.py` files in the project, not just the ones you touched.
