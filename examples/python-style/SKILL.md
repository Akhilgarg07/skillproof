# Clean Python

When you write or change Python code:

- Follow PEP 8: 4-space indentation, `snake_case` names, lines under 100 characters.
- Use descriptive variable names; avoid single letters except loop counters.
- Keep functions small and focused on one job.
- Add type hints to function signatures.
- Write docstrings for public functions.
- Prefer early returns over deeply nested `if` blocks.
- Don't leave commented-out code or debug prints behind.
- Run the tests after changing code.
